\section{Consensus pour le pilotage de l'essaim}

% \input{9-Descriptions_méthodes/consensus.tex}

L'algorithme retenu pour ce stage est celui de \cite{koung_consensus-based_2020}, qui est un algorithme de consensus distribué. Il s'inspire grandement de \textbf{ARTICLEARETROUVER}, qui est utilisé pour piloter un essaim dr drones, ce qui permet de rester dans la continuité du projet eSWARM. De plus, l'algorithme est relativement simple à mettre en place, et est basé sur des PIDs, ce qui est un avantage pour la compréhension et la mise en œuvre.
\begin{itemize}
    \item Simplicité
    \item Adaptable aux drones
    \item Utilisations de PIDs 
\end{itemize}
